================================================================================
                              TROUBLESHOOTING
================================================================================

PROBLEM: "No trading data for YYYY-MM-DD"
SOLUTION: Check dps.psx.com.pk - PSX may be closed or data not published yet
          Retry tomorrow, or switch to fallback: set DATA_SOURCE=ksestocks

PROBLEM: Import error / syntax error
SOLUTION: Run: python -m py_compile scraper_psx.py config.py main.py
          If passes, issue is elsewhere

PROBLEM: Network timeout
SOLUTION: PSX server may be slow/down. Retry later.
          Or fallback: set DATA_SOURCE=ksestocks

PROBLEM: Different prices vs ksestocks.com
SOLUTION: Normal - different data sources. Check PSX website for truth.
          PSX direct should be more accurate.
