# Overnight-Gap / Execution-Friction Study — Boring Breakouts

**Dates:** 2026-08-28 → 2026-08-30
**Status:** CONCLUDED — NEGATIVE (executable edge not demonstrable)
**Scope:** a follow-up thread to the main boring study, triggered by a live-trading
observation: the RS_60-conditioned Donchian breakout fires EOD on the close, but the
stock routinely gaps up the next open, so the backtested "fill at `Close(t)`" entry is
not achievable. This archive tests whether the edge survives real execution.

> **Read [`FINDINGS.md`](FINDINGS.md) first** for the consolidated verdict. The `reports/`
> files are the dated deliverables in the order they were produced.

---

## Verdict in one line

The Boring Breakout **as backtested** (fill exactly at the breakout close) shows a modest
edge; **as executable** it does not. Market-on-open entry takes net EV to ≈0; a working
limit at the signal price is firmly negative; the one positive-looking sub-rule
(take only gap ≤ 0, enter at the discounted open) is **not distinguishable from a matched
random-day control** on clean 2020–2026 data. The friction is structural to an EOD signal
on a market with overnight risk and a daily price limit.

## How to reproduce

All scripts are **read-only** (SELECT-only against the databases; writes go only to
`data/`). They locate the repo themselves via `scripts/_paths.py` — run them from anywhere:

```
cd scripts
python s3_fullhist_gap_distribution.py      # -> data/fullhist_gap_distribution.csv
python s4_fullhist_bucket_win_rates.py      # reads s3 output
python s5_salvage_tests.py                  # reads s3 output -> data/salvage_detail.csv
python s6_matched_control_2020_2026.py      # -> data/mc_*.csv
```

- **s3 → s4 → s5 → s6** is a chain (s4/s5 read s3's output; s6 is independent of s3 but
  reuses the same panels). s3–s6 are fully deterministic — they reproduce the numbers in
  `reports/02` and `reports/03` exactly.
- **s0 / s1 / s2** hit the live cloud `boring_signals` table. The `data/cloud_*.csv` are a
  **2026-08-28** snapshot (400 rows, pre-OI-7). OI-7 (2026-08-30) removed the 87
  `dedup_conflict` pairs, so re-running s1/s2 today gives ~237 rows and smaller counts.
  The cloud sample was always a minor sidebar; the substantive work is s3–s6.

## Method notes (shared across the thread)

- **Signal set:** the *existing* boring-study fires (`breakout == 1` in the panels). Signal
  generation is **not** recomputed anywhere in this archive.
- **Dedup:** first-fire-per-run (new run when the gap since the prior fire exceeds the
  lookback), matching `boring_donchian_trailing_stop_race_v2.build_run_population()`.
- **Universe:** restricted to symbols still in `prices_adjusted` after the 2026-08-27
  non-equity purge — drops ~75 futures contracts (`AIRLINK-JUN`, `786`, …) that had leaked
  into the pre-purge panels (3.6 % of breakout rows).
- **Exit rule:** HYBRID trailing stop, −8 % floor (unchanged from production).
- **Cost model:** round-trip 0.845 % (0.15 % brokerage ×1.15 FED + 0.25 % slippage, per
  side ×2) + 15 % CGT on a net-positive trade — the dashboard's documented model.
- **`open` data quality:** clean 2020→now; 14–30 %/yr missing 2005–2019 (unverified
  backfill). Any weight on pre-2020 numbers is provisional pending verification of that
  series.
